Every new page and interaction from the 2026-11-06 spec, in the site's tokens (paper surfaces, ink nav, Oswald display type, one forge accent). Sample data is illustrative. Dark mode comes from the palette remap and is not drawn separately.

1 · /teams — team directory (public)

Catalog entry "Team Tracker" under Tournament Tools. One table; the whole row links to the team. "Last major" is the newest archived event a member played while on the team, with the team's best finish there. A team without a logo gets an empty mark, never a broken image. Disbanded teams sit under the active ones, muted, with their date.

5b · /teams/inkborn-forge/manage — roster editor (admin or the team's manager)

Reached from "Manage roster" on the team page or the admin list. Name and link are editable by both roles; slug and manager are read-only here. Adding a member searches the archive's players (existing search-players), so every member is keyed by RPH player id from the start; the joined date defaults to today. "Left" is a date field per row; clearing it reinstates the member. Delete is for mistakes, not departures. Anyone else who opens this URL sees "Only this team's manager or an admin can edit the roster" and a link back to the team.

5c · A disbanded team: public page and the read-only manage page

After dissolution the public page keeps everything historical: no live card, everyone under Former members with the dissolution date as their leaving date, results untouched. The manage page is read-only for the manager and shows the notice; an admin also sees Reinstate, which clears the date and reopens exactly the memberships the dissolution closed. The team disappears from Tournament Lookup's picker because it has no current roster.
