# Lorcana Proxy Generator

A web app for generating printable 8.5×11 sheets of plain-text proxy cards for testing Disney Lorcana decks at home.

## Stack

- React + Vite
- Tailwind CSS
- Card data from [LorcanaJSON](https://lorcanajson.org/)
- Hosted on Vercel

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
